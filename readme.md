# A mod finally protected from the elements.
I've always wanted to make a good content mod, so here's an attempt at one, without any outside influence or silly restrictions.

## `Why is it called Conquest in Cataphract?`
With a newfound resolve, a previously wounded, but now healed, combatant in impenetrable armor is able to rise out of the ground and march endlessly onward toward their goal. A Conquest in Cataphract.

Developed by Vermin. Contact `undeathlyghost` on discord for more information.

[Can be found at this repository](https://github.com/SpencerDawg/Cataphract)
Depends on Broken Wings!

> [!IMPORTANT]
> This mod is work in progress and not designed for general usage yet. Please contact a developer before distributing it!
